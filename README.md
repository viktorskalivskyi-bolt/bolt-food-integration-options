# Bolt Food integration options

Інтерактивна партнерська презентація про 1-way та 2-way інтеграції для retail.

## Використання

1. Відкрийте `index.html`.
2. Введіть назву партнера у верхньому полі.
3. Натисніть **Завантажити PDF**.
4. У системному діалозі виберіть **Save as PDF / Зберегти як PDF**.

Назва партнера автоматично підставляється на всі релевантні слайди та у назву документа.
